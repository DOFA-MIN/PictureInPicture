# Политика конфиденциальности

Расширение **Picture In Picture** не собирает, не хранит и не передаёт никаких персональных данных пользователей.

## Что делает расширение

- Находит видеотеги `<video>` на открытой странице (YouTube, VK Видео, Rutube, Dzen и др.).
- Выводит выбранное видео в плавающее окно «Картинка в картинке» с помощью встроенного API браузера (`requestPictureInPicture`).
- Никакой код не загружается с удалённых серверов.

## Данные

Расширение не собирает, не обрабатывает и не передаёт:

- историю просмотров,
- адреса посещаемых сайтов,
- содержимое страниц,
- cookies, локальное хранилище или иные идентификаторы.

Все операции выполняются локально внутри вашего браузера. Данные не покидают устройство.

## Права доступа

Расширение запрашивает минимальный набор прав:

- `activeTab` и `scripting` — для временного встраивания скрипта на текущую вкладку только по действию пользователя (клик или горячая клавиша).
- `host_permissions` для `vk.com`, `vk.ru`, `rutube.ru`, `dzen.ru`, `zen.ru` — для работы плавающей кнопки на этих сайтах.

Эти права используются исключительно для функции «Картинка в картинке».
