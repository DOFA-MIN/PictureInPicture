# 🖼️ Picture In Picture

Расширение для Chromium (Chrome, Edge, Brave, Yandex.Browser и др.), которое выводит видео со страницы в плавающее окно **«Картинка в картинке» (PiP)** одним кликом.

[![Chrome Web Store](https://img.shields.io/badge/Chrome%20Web%20Store-Install-blue?logo=google-chrome)](https://chrome.google.com/webstore)
[![Manifest V3](https://img.shields.io/badge/Manifest%20V3-Ready-green)](https://developer.chrome.com/docs/extensions/mv3/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

## ✨ Возможности

| Сервис | Как активировать |
|--------|------------------|
| **YouTube** | Плавающая кнопка на видео + `Alt+P` + иконка панели |
| **VK Видео** (`vk.com`, `vk.ru`) | Плавающая кнопка на видео + `Alt+P` + иконка панели |
| **Rutube** (`rutube.ru`) | Плавающая кнопка на видео + `Alt+P` + иконка панели |
| **Dzen** (`dzen.ru`, `zen.ru`) | Плавающая кнопка на видео + `Alt+P` + иконка панели |
| **Любой другой сайт** | Клик по иконке расширения или `Alt+P` |

- Наведите курсор на видео — появится иконка PiP в правом верхнем углу плеера.
- Кнопка становится синей, когда PiP включён; повторный клик возвращает видео на вкладку.
- В окне PiP есть нативные кнопки Chromium: **пауза, перемотка, «Вернуть на вкладку», закрытие (`×`)**.
- Если на странице несколько видео, выбирается самое подходящее (играющее + самое большое).
- Работает с встроенными плеерами (iframe).

## 📦 Установка

### Из исходников (режим разработчика)

1. Скачайте репозиторий:
   ```bash
   git clone https://github.com/ваш-логин/picture-in-picture.git
   ```
2. Откройте браузер и перейдите на `chrome://extensions` (или `edge://extensions`).
3. Включите **Режим разработчика** (переключатель в правом верхнем углу).
4. Нажмите **Загрузить распакованное расширение** и выберите папку репозитория.
5. Закрепите иконку на панели через меню пазла 🧩 (опционально).

## 🖥️ Использование

**На YouTube, VK Видео, Rutube, Dzen:**

1. Откройте видео.
2. Наведите курсор на видео — появится иконка PiP в правом верхнем углу.
3. Нажмите на неё — видео откроется в плавающем окне.
4. Снова нажмите на иконку (или кнопку `×` в окне PiP) — видео вернётся на вкладку.

**На любом другом сайте:**

- Нажмите на иконку расширения или клавиши **`Alt+P`**.

## ⚠️ Ограничения

- Не работает на внутренних страницах браузера (`chrome://`, `edge://`, магазин расширений, PDF) — туда нельзя внедрить скрипт. В этом случае на иконке замигает красный бейдж `!`.
- На некоторых сайтах PiP может быть заблокирован владельцем видео (`disablePictureInPicture`) — красный бейдж `!`.
- Требуется Chromium 102+ (Manifest V3 + `scripting.executeScript`).
