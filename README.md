# Picture In Picture

Расширение для Chromium (Chrome, Edge, Brave, Yandex.Browser и др.), которое выводит видео со страницы в плавающее окно «Картинка в картинке» (PiP).

## Что делает

- **На YouTube, VK Видео, Rutube, Dzen:** поверх видео появляется плавающая кнопка «Картинка в картинке» (как в Firefox / Microsoft Edge). Наведите курсор на видео — кнопка покажется в правом верхнем углу плеера. Клик — видео уходит в поверхностное окно, повторный клик — возвращается на вкладку.
- **На других сайтах:** кликните на иконку расширения на панели или нажмите **`Alt+P`** — видео уйдёт в PiP.
- В окне PiP есть нативные кнопки Chromium: **пауза, перемотка (шкала), «Вернуть на вкладку» и закрытие (`×`).
- Если на странице несколько видео, выбирается самое подходящее (играющее + самое большое). Видео внутри встроенных плееров (iframe) тоже поддерживается.

## Как установить

1. Скачайте/склонируйте этот репозиторий.
2. Откройте браузер и перейдите на `chrome://extensions` (или `edge://extensions`).
3. Включите **Режим разработчика** (переключатель в правом верхнем углу).
4. Нажмите **Загрузить распакованное расширение** и выберите папку `PictureInPicture`.
5. Иконка появится на панели расширений (при необходимости закрепите её через меню пазла 🧩).

## Как пользоваться

**YouTube, VK Видео, Rutube, Dzen:**
1. Откройте видео.
2. Наведите курсор на видео — появится иконка PiP в правом верхнем углу.
3. Нажмите на неё — видео откроется в плавающем окне. Кнопка станет синей, пока PiP включён.
4. Снова нажмите на иконку (или кнопку `×` в окне PiP) — видео вернётся на вкладку.

**Любой другой сайт:**
- Нажмите на иконку расширения или **`Alt+P`**.

## Структура

```
manifest.json      — манифест MV3, права, action, content-скрипты, горячая клавиша
background.js      — сервис-воркер: клик по иконке, fallback для остальных сайтов
content/youtube.js — плавающая кнопка PiP на YouTube
content/video-sites.js — плавающая кнопка PiP на VK, Rutube, Dzen
scripts/make-icons.ps1 — генератор иконок (PowerShell)
icons/             — готовые иконки 16/32/48/128
README.md          — эта инструкция
```

## Ограничения

- Не работает на внутренних страницах браузера (`chrome://`, `edge://`, магазин расширений, PDF) — туда нельзя внедрить скрипт. В этом случае на иконке расширения замигает красный бейдж `!`.
- На некоторых сайтах PiP может быть заблокирован владельцем видео (`disablePictureInPicture`) — красный бейдж `!`.
- Требуется Chromium 102+ (Manifest V3 + `scripting.executeScript`).
